# TaskFlow – To-Do List & Scheduling Website
Open `index.html` in any browser. No install or server needed. Tasks are saved in your browser's localStorage.

```
TaskFlow/
├── index.html      Dashboard
├── tasks.html      My Tasks (add / edit / delete / complete / filter)
├── calendar.html   Monthly calendar
├── css/style.css   Styling + responsive layout
└── js/
    ├── app.js        Shared storage, helpers, task form
    ├── dashboard.js  Dashboard page logic
    ├── tasks.js      My Tasks page logic
    └── calendar.js   Calendar page logic
```
